# McLaren Apex Archive

Immersive single-page 3D racing experience built with Vite, React, React Three Fiber, Drei, Lenis, GSAP and ScrollTrigger.

## Run locally

```bash
pnpm install
pnpm dev
```

The GLB model is included at `public/models/mclaren-f1.glb`.

## Build

```bash
pnpm build
pnpm preview
```
